# Changelog

All notable changes are documented here. This project follows semantic
versioning while its public interfaces remain explicitly early-stage.

## [0.1.0] - 2026-08-14

### Added

- Observable `collect -> analyze -> decide -> report -> alert` pipeline.
- Provider, tool, stage, scheduler, and trigger extension interfaces.
- Static reference provider, rule-based stages, CLI, and structured JSON output.
- Simulated market, news, and security monitoring examples.
- Unit tests, GitHub Actions, bilingual documentation, and OSS governance files.
