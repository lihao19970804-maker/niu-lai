# 牛来 (NiuLai) roadmap

牛来 is intentionally small at v0.1.0. Priorities will be refined through
issues and contributor feedback rather than implied as completed features.

## v0.2 — reliable extension foundations

- Stabilize provider and tool result schemas.
- Add durable scheduling, idempotency keys, retries, and run persistence.
- Add webhook alerts with signing, redaction, and delivery receipts.
- Document a complete provider quickstart and compatibility policy.

## v0.3 — operational visibility

- Structured event export and OpenTelemetry-compatible traces.
- Pluggable report storage and run inspection.
- Backpressure, rate-limit, timeout, and cancellation policies.
- Security hardening for untrusted provider input and configuration.

## Later exploration

- Distributed workers and gateway/platform adapters.
- Human approval checkpoints for sensitive agent actions.
- Evaluation fixtures for monitoring quality and alert fatigue.
- Optional LLM analyzers with provider-neutral contracts and cost controls.
